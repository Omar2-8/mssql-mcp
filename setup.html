mssql-explorer setup

Define your database connections, choose access levels, configure the VPN, and connect the server to Claude Desktop. Everything stays on this machine.

Defaults

Applied to any connection that doesn't set its own value.

Connections

Name each connection whatever you like. Access level controls what queries are allowed.

Templates (advanced, optional)

Auto-generate many connections from a naming pattern. Leave as [] if you don't need it. Edited as raw JSON: a list of templates. Pasting a whole db.config.json here loads it into the entire form.

VPN

Choose how the server handles the network. For Azure Entra ID / OAuth VPNs (sign-in with MFA), use "Detect & wait" and connect the Azure VPN Client yourself, or "Launch command" to have the server start it (a sign-in window will appear).

Space-separated or a JSON array. For OAuth this launches the client and a sign-in / MFA window appears.
